The challenge

Production computers live by different rules.

In most plants, the computers closest to production are also the hardest to protect. They run the software operators and engineers depend on every shift, and they can't simply be patched, rebooted or replaced when an IT policy says so.

01

Availability first

Stopping a line to install an update can cost more than the update is worth. Changes wait for planned shutdowns.

02

Long lifecycles

Operator stations often run for a decade or more, sometimes on operating systems that no longer receive mainstream support.

03

Vendor-qualified software

Control and HMI software is qualified for a specific configuration. Changing that configuration can put support and stability at risk.

04

Limited connectivity

Many plant networks are segmented or isolated by design, so tools that depend on constant cloud access struggle there.

What we focus on

The computers between people and process.

Our OT security work centres on the computers on the plant floor: the machines operators and engineers use to see, control and maintain production.

  • Operator stations and HMI computers
  • Engineering workstations used to configure and maintain control systems
  • Plant-floor PCs that run production, quality and maintenance software

How we approach it

Secure by design, sized to the plant.

Our work is informed by widely used industrial security guidance, such as IEC 62443 and NIST SP 800-82: understand the plant, separate what must be separated, control change, and make the current state clear to the people responsible for it.

Questions

Frequently asked.

What is the difference between IT security and OT security?

IT security protects information: data, email and business systems. OT security protects operations: the systems that run machines and processes. In OT, availability and safety come first, systems run for many years, and changes must fit around production.

Why don't standard IT security tools fit plant-floor computers?

Many IT tools assume frequent updates, constant internet access and current operating systems. Plant-floor computers often have none of these, and their software is qualified for a fixed configuration, so tools that change that configuration can disrupt production.

What is IEC 62443?

IEC 62443 is a series of international standards for the security of industrial automation and control systems. It covers how to organise systems into zones, how to manage access and change, and what security capabilities components should have.
